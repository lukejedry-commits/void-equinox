# Void Equinox: Ashes of Autumn

Vite + three.js + Rapier (`@dimforge/rapier3d-deterministic-compat`, WASM inlined so it bundles for GitHub Pages). Plain JS.

- `npm run dev` (port 5173) · `npm run build` · `npm test` (headless node tests)
- Controls: WASD move, Space dodge, backtick toggles perf overlay, top-right quality menu (persisted).
- Placeholder tuning numbers are marked `TODO(Mechanics)` in `src/player/controller.js`.
